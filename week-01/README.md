
# Small Python Data-Processing App

A Python project for loading, cleaning, and analyzing student performance data using pandas and NumPy.

## Features
- Load data from a CSV file
- Check missing values and duplicates
- Clean data using functions
- Calculate grade statistics and percentages
- Compare G1, G2, and G3 grades

## Technologies
- Python
- NumPy
- pandas
- Jupyter Notebook

## Setup

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

## Usage

Open `data_processing.ipynb` in VS Code or Jupyter Notebook and run all cells. The dataset should be located at `data/student-mat.csv`.

## Dataset

[UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)
